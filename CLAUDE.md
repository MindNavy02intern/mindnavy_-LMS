# Claude Project Instructions

Always follow these rules in this project:

1. For any project architecture, authentication, routing, backend, frontend, Prisma, Supabase, or file-structure question:
   - First read graphify-out/GRAPH_REPORT.md.
   - Then inspect only the relevant parts of graphify-out/graph.json if more detail is needed.
   - Then open only the specific source files that are relevant.

2. Do not read graphify-out/graph.html unless the user explicitly asks.
   graph.html is only for browser visualization and is too large.

3. Do not scan the whole project unless absolutely necessary.
   Use the Graphify report/graph first to find the correct files.

4. Before editing files, explain what you found and ask for confirmation.

5. Keep explanations simple and clear because the user is still learning.
