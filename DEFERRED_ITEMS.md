## ⚠️ Structural note (read first)

There is **no learner-facing or instructor-facing application anywhere in this codebase** — everything that exists is the admin console. Several items below that read like "deferred features" are actually blocked on that larger fact, not on a small missing endpoint:

- Quiz-taking (`QuizAttempt`) has an admin-facing half only (reopen/reset/grade) — no one can actually *take* a quiz.
- Learning Path / course progress tracking has no consumer that writes real progress.
- Certificate auto-issuance triggers (completion, passing grade, attendance) have nothing to fire off.
- Support tickets, instructor reviews, and refund requests can only be *created* by an admin standing in for a user, because there's no user-facing surface to create them from.

Treat every item below tagged **[needs student app]** as downstream of this one fact, not as an independent gap.

## ❌ Blocked (needs an external service/credential before any further work is meaningful)

### Payment gateway (Stripe / PayPal / Razorpay / Apple Pay / Google Pay / bank APIs)
No real gateway is connected anywhere. This is the single largest blocked surface — it cascades into:
- Finance → Payment Gateways tab (`frontend/src/components/finance/PaymentGatewaysTab.tsx`) — Connect buttons disabled, static UI.
- Finance → no `Plan` model, `plan.create/update` dead; `payment.retry`/`payment.approve` dead aliases (`IMPACT_MAP.md §5.13`).

- Integrations → Payment tab, all provider cards are `COMING_SOON` (`backend/src/services/integrations.service.js:14-18`, Stripe/PayPal entries).
- Refunds work today only because approve jumps straight to a terminal state without ever waiting on a gateway — a documented shortcut, not a bug.

### Cloudflare Stream (video hosting)
Current video upload is a Supabase Storage stand-in, hard-capped at 50MB, no transcoding. `backend/src/services/uploads.service.js:18-21`, `backend/src/services/storage/index.js:15-16, 22` (the `cloudflare` provider is a commented-out stub in the adapter map). Affects Course Builder video lessons and Content Library size limits.

### Zoom credentials
`POST`/schedule-changing `PATCH` on Live Sessions return `503 { message: 'Zoom is not configured…' }` until server-side Zoom credentials are set. Classroom features (chat, screen share, whiteboard, polls, recording) are entirely gated behind this. `LIVE_SESSIONS_CONTRACT.md`, `docs/blueprint/pages/04-learning-management.md`.

### FCM (push notifications) / Twilio (SMS)
Every push/SMS send across the system — Notifications module, Emergency Alerts, System Settings toggles — is logged `PENDING` and never actually attempted. `backend/src/services/notifications.service.js:225-233, 510-513`.

### SSO / SAML / LDAP / OAuth (Google, Microsoft, Okta, Azure AD)
Authentication tab in Integrations and the social sign-in toggles in System Settings both need real provider registration before they can do anything. `INTEGRATIONS_CONTRACT.md`.

### HR/ERP and CRM systems (SAP, BambooHR, Salesforce, HubSpot, Workday, Oracle HCM, Zoho CRM)
All `COMING_SOON` catalog rows with zero backing code — `connect`/`disconnect`/`test`/`sync` short-circuit to `{success:false, message:'Configure API keys to activate.'}` without touching any real or fake API. `backend/src/services/integrations.service.js:67-84`.

### Cloud storage beyond Supabase (AWS S3, Google Drive, GCS, Azure)
Integrations → Storage tab catalog rows, no backing provider. Same pattern as HR/CRM above.

### SIEM / enterprise monitoring
Audit & Security's SIEM & Enterprise Monitoring tab is `[phase-later]` and is inherently a third-party integration, not something to build standalone. `docs/blueprint/pages/13-audit-security.md`.
